# 0007 · 入库前用 nh3 净化正文 HTML（部分取代 ADR 0003）

- 状态：accepted
- 日期：2026-09-04
- 部分取代：ADR 0003（其「不加净化依赖、交由客户端」的取向被本 ADR 反转；CDATA 与 lxml 的选择仍有效）

## 背景

ADR 0003 决定正文以 CDATA 原样透传，并明确写了「不引入净化器，交给阅读器自己的规则」。

实现后接入 NetNewsWire，发现这个决定**没有被真正执行**：`normalize()` 用 `plain_text()` 把标签全部剥掉后才存储，于是

- 存进去的正文没有任何标记语言
- CDATA 包裹的是纯文本 —— ADR 0003 想要的「保留链接与排版」收益**完全落空**
- NNW 里文章无链接、无格式

根因是一个函数承担了两个职责：`plain_text()` 既用于**算 content_hash**（这里必须去标签，否则同一篇文章在两个源里因 HTML 差异算出不同哈希，跨源去重 B2 失效），又用于**决定存什么**（这里不该去标签）。

## 决策

1. **正文存储源 feed 的原始 HTML**；`plain_text()` 只用于算哈希、派生标题、判断「有无可读正文」
2. **入库前用 nh3 净化一次**（`adapters/sanitize.py`），而非每次输出时净化
3. `content_hash` 的计算方式不变（其内部本就 `plain_text`），所以跨源去重行为不受影响

## 理由

### 为什么净化

ADR 0003 说「依赖阅读器自己的净化规则」。这个依赖是**不可验证的**：我们无法确认每个客户端都做对了，而做错一次的后果（XSS、追踪像素、远程图片加载）由用户承担。在自己进程内净化，把安全性从「希望客户端做对」变成「我们自己保证」。

### 为什么在入库时净化，而不是输出时

- **纵深防御**：存储的内容已经是干净的，未来任何新输出路径（MCP Resource、全文搜索、导出）默认安全，不需要「记得净化」——而每次渲染净化正是要靠人记住的模式
- **成本**：净化一次，而不是每次请求都净化
- **一致性**：RSS 与 Reader API 必然给出同样的正文

### 为什么接受 nh3 这个依赖

ADR 0003 曾为「避免第二个 C 扩展」而不加净化库。这个权衡被**有意反转**：

| | 不净化 | nh3 |
|---|---|---|
| 依赖 | 零 | 第二个 C 扩展（已有 lxml） |
| 安全来源 | 客户端实现 | 我们自己 |
| 供应链面 | 小 | 多一个需持续关注的包 |

判断依据：安全属性不该外包给无法审计的对端。代价是真实的（多一个 C 扩展、多一条供应链），但可管理。

## 实现要点

`adapters/sanitize.py` 用**显式允许列表**：标签、按标签的属性、URL scheme。

- 允许：排版与结构标签、`a[href]`、`img[src|alt|...]`、表格
- 禁止：`script`/`style`/`iframe`/`object`/`embed`/`form`/`input`/`svg`、所有 `on*` 事件属性、`style` 属性、`data-*`、`javascript:`/`data:`/`vbscript:` URL
- **被丢弃的标签连内容一起丢**（`clean_content_tags`）：只剥标签会把脚本源码留成可见文本
- **唯一豁免（2026-09-13）**：`img` 的 `class` 属性经 `attribute_filter` 按
  **值**放行，且只接受单个固定常量 `pearss-avatar`（其余 class 值照旧整属性
  丢弃）。动机：RSS 协议没有作者头像通道，头像只能内联在正文里；这个常量
  是阅读器/主题挂 `border-radius: 50%` 的样式钩子。安全分析：放行的不是
  class 属性本身而是**一个字面量**——注入面为零，风险等级与 img 标签本身
  相同；`style` 内联样式仍然全面禁止。实现注意：nh3 对白名单内**每个**属性
  调用过滤器且 None 即剥除，所以非 class 属性必须原样返回（首版过滤器在这
  里剥掉了全部 src，靠「class 与 src 同框」的测试抓出）
- `filter_style_properties` 必须传 **frozenset 而非空元组**：nh3 的绑定对 tuple 抛 `TypeError`，而 `()` 是最自然的字面量写法，极易踩

## 验证

- 31 个净化单元测试（执行向量、事件属性、危险 URL、SVG、注释、幂等性）
- 真实数据：45 条中 43 条保留标记、42 条含可点击链接，**危险构造 0 条**
- nh3 自动为链接加 `rel="noopener noreferrer"`，远程页面无法回指阅读器窗口
- 跨源去重仍正确（`test_dedupe_is_unaffected_by_markup_differences`）

## 后果

- NNW 里能看到链接与排版，ADR 0003 的 CDATA 选择终于有意义
- 存储内容即安全内容，新输出路径无需重复净化
- **已入库的条目不会自动重净化**：改变净化规则需重新摄取（本次即清空重灌）
- nh3 需纳入依赖更新关注范围

## 可逆性

可逆。去掉净化即回到 ADR 0003 原状（删 `pipeline` 里的一处调用）；把正文改回纯文本则同时使 CDATA 与 nh3 都不再必要，可一并移除 lxml 之外的这两个决定。
